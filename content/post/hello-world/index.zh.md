欢迎来到我的数字花园——其实就是个记录学习过程的地方。

这是重建后的第一篇文章，按惯例聊聊：为什么又折腾了一遍博客，以及以后打算在这里写什么。

## 为什么重建

之前用的是 WordPress，能写，但慢慢觉得不太适合自己：

- 想改一点样式，得跟主题较劲半天；
- 想加个小功能，插件装来装去，越装越乱；
- 服务器到期了还得记得续费，一忘就是一片空白。

这次索性换成 Hugo，配上开源的 Stack 主题：文章全部是 Markdown 文件，放在仓库里版本管理，排版交给主题，样式上的小调整再自己补。写东西的时候少了很多杂音。

> 顺带一提：旧站的文章之后会慢慢搬过来，不着急，一篇篇来。

## 之后写什么

没有严格的选题计划，大概会围绕：

1. **学习笔记**——课程、看书、看文档之后整理的东西；
2. **CTF 与安全**——练习过程中遇到的好玩题目和踩坑记录；
3. **折腾日志**——Linux、自建服务、各种工具，以及搞坏又修好的过程。

内容不会很高深，毕竟我也还在学。但有一点可以保证：**都是自己动手试过的**，写下来先是为了自己以后能翻回去看。

## 关于这个站

技术上是这样搭起来的：

```bash
# 大概就是这样
hugo new post/hello-world/index.md
hugo server -D
```

- 框架：Hugo
- 主题：Stack
- 托管：GitHub Pages

就这样，开工。🌱
